更新章节

完整变化，分章呈现

所有更新都在这里，浏览时不会迷失位置。

01

新增

1 项变化
  • GPT-6.1 Terra 计价。 支持标准、Fast、Flex 和长上下文 API 等值估算，包含缓存读取与写入。
02

变更

5 项变化
  • 发布检查。 将重复网站检查合并到可移植门禁，保留手动 Node 20 兼容性检查，并消除发布锁测试对请求完成顺序的依赖。
  • 协作规则。 统一通过 squash PR 合并并保留远程分支自动删除，本地分支和 worktree 沿用现有归档流程。
  • 官网设计。 项目官网统一为 timmyagentic 视觉风格，保留原有安装、下载与文档入口。
  • 模型明细。 趋势图例默认按模型折叠显示总量，展开后查看 Standard、Fast、Ultrafast 或 Flex 子项，Token 总量与占比口径保持不变。
  • 新官网地址。 产品链接、私有测试版服务和匿名版本统计迁入个人官网域名。
03

修复

1 项变化
  • 挂件定位。 使用顶栏中最宽的无障碍空隙，避免因标题旁第一段空隙过小而隐藏额度挂件，同时继续避让邻近控件。
