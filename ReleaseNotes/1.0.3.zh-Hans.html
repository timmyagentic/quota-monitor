所有更新都在这里，浏览时不会迷失位置。

01

变更

4 项变化
  • 统一完整刷新操作。 Dashboard 的重新加载现在与菜单栏共用完整的最新数据流程，包括实时额度请求及本地 Codex／Claude 历史扫描；History 与 Sessions 仍保留聚焦的分页重载。
  • 近期 Dashboard 只读一遍。 趋势、月度统计、当前与前一周期模型占比及 Provider 占比现在会从一次兼容混合时间戳的事件读取中派生，并共用相同时间、Provider 范围、本地日历与 DST 边界。
  • 始终先展示上次有效 Dashboard。 兼容快照会跨窗口重挂载和应用重启保留；普通重开在数据未变化时跳过读取，快照过期时也会继续留在屏幕上，只由一次带 generation 门禁的后台刷新原位更新。
  • Private Beta 内直接晋级 Stable。 更新的 Stable 构建现在可以与最新 Private Beta 一起镜像到鉴权 feed，已授权设备无需切换通道即可发现构建号更高的 Stable，并且所有携带设备 token 的请求都只会发往 Quota Monitor 自有域名。
02

修复

6 项变化
  • 完整计算 GPT-5.6 与长上下文费用。 Codex 导入会保留提示缓存写入；内置 catalog 现在物化所有受支持的 Short/Long × Standard/Flex/Fast 与历史最终价格行，事件只选择一个最终行，不再运行时乘价格倍率。GPT-5.6 Sol 在 OpenAI 2026-08-21T19:34:10Z 官方公开公告时从上市价切到促销价，Terra/Luna 保留 7 月 30 日切点；GPT-5.6+ cache write 按 input 的 1.25 倍，旧模型无额外 write charge、按 input 1.0 倍。旧 LiteLLM/local 行以及 bundled Claude/GLM 行不能进入 Codex 分支。升级迁移会安装完整目录并立即重算已有事件，即使原始 rollout 已不可读，金额也不会继续滞留。
  • 统一趋势的滚动时间口径。 7 天、30 天、90 天与一年趋势现在会先按精确的最近 7 × 24、30 × 24、90 × 24 或 365 × 24 小时筛选用量，再按本地日期分组，边界日中更早的那部分记录不会再抬高 token、费用或缓存命中率。
  • 立即恢复被重写的 Codex 历史。 当已提交的 checkpoint 不再匹配当前日志时，Quota Monitor 会在下一次扫描从头解析完整文件并在事务中替换该会话；文件尾仍不完整时继续保留上一次正确数据，也不再用两秒等待把未来修改时间的来源无限期推迟。
  • 始终采用最新摘要刷新。 Scan、Settings 与重叠的 Dashboard 请求现在会合并为最多一次 trailing pass，并使用最新筛选与启用工具；旧的菜单栏或 Dashboard 读取不再覆盖更新结果。
  • 趋势不再等待 Activity。 Dashboard 汇总、Forecast、趋势与构成会先发布，全历史 Activity 随后独立计算，最慢的卡片不再让整个窗口停留在加载状态。
  • 准确说明 Claude 刷新节奏。 高级设置现在会说明 Claude live quota 独立地约每十分钟刷新，不再显示已经过时的两小时间隔。
