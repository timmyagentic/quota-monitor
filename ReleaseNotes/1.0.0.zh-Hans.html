01

新增

9 项变化
  • 当前性能审查。 扫描导入、计价、Dashboard、启动和菜单栏热点路径的性能审查现在会依据当前 main 重新核对全部原始发现，分别标记已交付、部分交付与仍待处理的工作，并重新排列后续改进顺序；应用行为本身不变。
  • 私有 Beta 更新通道。 受邀用户按住 Option 点击“立即检查”后才会显示一次性授权码入口；授权后可切换稳定版与私有 Beta 并通过 Sparkle 获取需鉴权的更新，其他用户只会看到普通更新控件，Beta 文件也不会进入公开 GitHub Release 或更新源。
  • 可重看的近期新功能演示。 重要版本可以在既有用户下一次主动操作应用时展示一次双语离线导览，支持随包图片、静音视频与封面降级、“减少动态效果”、键盘导航，并在设置中保留永久重看入口；全新安装仍直接完成首次设置，不会紧接着再看更新导览。
  • Quota Monitor 1.0 产品导览。 既有用户会看到一套四页双语导览，集中介绍新的 Codex 窗口挂件、大历史性能、按生效日期计价与更安静的更新，并使用可离线重看的公开安全素材。
  • 完整的 1.0 更新特刊。 1.0 更新窗口不再只放四张亮点卡片，而是改用更醒目的发布舞台、快速导览、章节导航与中英双语完整变化。
  • Dashboard 缓存命中率趋势。 顶部摘要现在会同时显示今日、近 7 天和近 30 天的结果；每日缓存命中率折线会跨过无可计算数据的日期连接相邻观测点，而不会将其当成 0%，Provider 与日期筛选仍会同步更新两处数据。
  • 本地索引与账户使用画像。 Dashboard 筛选为 Codex 时，“使用画像”可在原卡片内切换现有本地指标与账户汇总及每日热图。
  • 历史页面每日缓存命中率。 选择日期后，顶部摘要会在“今日使用的模型”上方直接显示按 Token 加权的缓存命中率。
  • Fable 5 专用周限额。 当 Anthropic 提供模型专项周限额时，Quota Monitor 会在重启后继续保留，并将两个周限额分别标记为 Full 和 Fable 5。
02

修复

14 项变化
  • 精致统一的 Codex 挂件。 自适应底色和浅边框会融入 Codex，5h／7d 标签与状态栏一致；能够识别时会跟随 Codex 的帮助控件，无法识别时会按窗口尺寸缩放兜底位置；更窄的品牌详情卡会匹配字体和语义进度色，只保留配置中的百分比，并在移开指针或点击外部后自然关闭。
  • 挂件随 Codex 窗口保留。 切换到其他应用后，紧凑挂件仍会贴在可见的 Codex 窗口上，普通前台窗口会自然盖住它；后台状态下的点击会直接传递给 Codex，悬停详情会立即关闭，而最小化、隐藏、关闭 Codex 或切到其他桌面仍会隐藏挂件。
  • 日期跟随应用语言。 会话、历史、使用画像和趋势中的可见日期与时间现在会使用 Quota Monitor 选择的语言格式化，不再跟随 macOS 系统语言。
  • 响应式 Token 活跃度热图。 全年热图会在 Dashboard 默认宽度下使用紧凑布局，为末尾月份标签预留空间，并仅在更窄窗口中回退到横向滚动。
  • 私有 Beta 分段下载。 通过授权的完整下载现在会返回正常完整响应；有效的单段字节范围会根据已校验请求与对象大小给出准确的 Content-Range，后缀范围也会转换成明确的偏移读取，即使存储未返回可用的范围元数据也能正常续传，格式错误的范围仍会安全拒绝。
  • 稳定的原生 Codex 额度。 挂件会跟随当前 Codex 窗口，在 Codex 进入后台或关闭 Codex 跟踪时自动隐藏，避免启动阶段重复请求，刷新期间保留上次正确额度、过滤已经过期的主动重置卡并自动重试数据获取，不再要求用户重启，同时恢复旧版悬停详情卡中的用量、进度和重置时间。
  • GPT-5.6 分段定价。 7 月 30 日前的 Terra 与 Luna 用量保留上市价，之后的 Standard、Fast、Flex 与长上下文估算改用 OpenAI 新价格。
  • Claude Opus 5 定价。 内置价格目录现在包含 Anthropic 官方公布的 Opus 5 输入、输出、缓存读取与缓存写入费率，因此新导入用量会直接由应用计价，不再继续显示为 $0。
  • Claude Sonnet 5 标准定价。 内置价格目录现在按 Anthropic 原价为 claude-sonnet-5 使用每百万 Token 输入 $3、缓存读取 $0.30、5 分钟缓存写入 $3.75、1 小时缓存写入 $6、输出 $15 的费率，使其历史费用不再保持 $0，也不再因用户旧有本地目录不同而产生差异。
  • 真正有边界的会话分页。 会话列表现在读取由触发器持续维护的汇总，并用索引化 keyset 游标按固定 50 条继续加载，滚动时不再全量聚合用量历史或反复计算不断增长的前缀。
  • 可靠发布私有 Beta。 发布工具和生产存储锁现在使用已部署服务接受的请求形式，使需鉴权的 Beta 上传可以顺利完成，同时不放宽访问控制。
  • 准确显示 Claude 低用量。 Claude 的 0...100 用量百分比现在会在额度窗口刚开始时保持原值，不再把 1% 误判成旧式比例并显示为 100%。
  • 恢复后显示最新 Dashboard。 从最小化状态恢复 Dashboard 时现在会刷新一次摘要和图表，同时避免在窗口保持最小化期间反复执行 Dashboard 工作。
  • 跨午夜保持缓存窗口准确。 已打开的 Dashboard 现在会在本地日期变化时刷新今日、近 7 天和近 30 天缓存命中率窗口，跨过午夜后不会把昨天的数值继续标成今日。
03

变更

22 项变化
  • 仅使用随包价格。 费用估算现在只使用 Quota Monitor 版本内置的价格目录；随包费率变化时，按生效日期计价仍会保留 GPT-5.6 的历史费用。
  • 更轻量的本地化日期格式化。 菜单弹窗与会话页面重复渲染时现在会复用按语言和时区区分的日期格式化器，同时保持英文与简体中文输出不变。
  • 更流畅的热图悬停。 指针移动时，Token 活跃度提示信息现在会复用已准备好的全年网格，避免重复执行整年计算，同时保持等级、月份标签和响应式布局不变。
  • 更流畅的趋势日期查看。 图表、所选日期提示与图例现在会共用同一份 Provider 或模型趋势结果，只有来源数据、范围、分组、日历或语言变化时才重新派生，在保持总量与顺序不变的同时避免重复筛选和聚合。
  • 更轻量的启动环境检查。 普通进程读取现在只解析一次本地 QA 路由，减少设置与诊断路径的重复工作，同时不会缓存运行时偏好，也不改变 QA 隔离行为。
  • 有边界的 Codex 元数据刷新。 会话标题与项目信息来源未变化时会直接复用；元数据变化后只主动修正最近七天有活动的会话，新导入或 rollout 发生变化的会话仍会使用最新元数据。
  • 私有 Beta 打包隐私。 维护者可以对已合入的精确源码版本完成 Developer ID 签名与公证，构建环境只会交出由一次性接收密钥加密的产物，同时不会触碰公开 Release 或更新源。
  • 由窗口承载的 Codex 挂件。 Quota Monitor 现在自行在 Codex 账户行原有的右侧位置绘制紧凑的 5 小时和每周读数，跟随窗口移动与空间切换，不遮挡周边账户控件，并可通过悬停或点击打开详细信息。
  • 更安静的日常扫描。 文件监听和日常刷新触发扫描时，菜单弹窗只在右上角显示小型加载图标，不再展开详细扫描条；启动和首次设置后的导入仍保留完整进度。
  • 更温和的一键更新。 自动检查发现新版本时只显示现有应用内更新图标；点击后立即开始下载与校验，以紧凑状态反馈进度，并仅在更新准备完成后弹出重新启动提示，同时“立即检查”仍会显示明确结果。
  • 更快的迁移会话查找。 导入状态现在会索引已关联的会话 ID，rollout 文件移动时无需扫描整张状态表，同时不会把尚未关联的记录放入索引。
  • 更低的 rollout 解析开销。 每次 Codex rollout 扫描现在会在多条记录之间复用一个局部 JSON 解码器，同时保持原有逐行解码行为不变。
  • 更及时的后台更新检查。 启用自动检查后，Quota Monitor 启动、系统唤醒或重新进入前台时，如果此前从未检查或距离上次检查已超过六小时，现在会发起静默更新检查；关闭自动检查后仍可使用“立即检查”。
  • 更安静的菜单栏更新。 后台状态变化后，只有可见行、样式或语言确实改变时，才会重新构建并写入原生状态栏标题。
  • 更流畅的会话搜索。 连续输入会取消尚未执行的搜索刷新，在输入停顿后只发起一次数据库查询，不再为每次按键重复执行同一批完整会话查询。
  • 聚焦增量计价。 Codex 与 Claude 的增量导入现在只重新计算本次插入或更新的用量记录；完整重建与价格目录全量刷新仍会覆盖全部记录。
  • 更快的菜单栏用量汇总。 累计、7 天与 30 天 Provider 统计现在共用一次本地历史遍历，在保持时间窗口和数值不变的同时减少刷新开销。
  • 更安静的后台刷新。 启动时只加载菜单栏摘要，不再预载尚未显示的 Dashboard；频繁的文件监听扫描在导入无变化时会跳过摘要工作，而打开菜单栏弹窗或主动刷新仍会更新时间相关的统计。
  • 可靠的窗口级程序坞状态。 应用窗口或更新窗口关闭后，Quota Monitor 会等待 AppKit 完成关闭，再重新检查仍打开、已最小化及更新窗口，然后回到仅菜单栏模式；macOS 可能另行保留“最近使用”快捷项，但这不代表运行中的程序坞图标仍然存在。
  • 更宽的历史首屏范围。 历史页面首次加载最近 21 个自然日；填充窗口与主动向下滚动时仍保持原有的 7 天增量分页。
  • Dashboard 自适应初始尺寸。 Dashboard 首次打开时会根据触发它的显示器可用工作区调整大小并居中显示，之后打开仍会恢复用户保存的大小和位置。
  • 更精简的贡献者测试流程。 本地迭代现在只运行受影响的 suite，会复用内容未变时已通过的 Swift 结果，并把完整 suite 的成功输出收敛为摘要，同时不降低最终 PR 门禁强度。
04

移除

3 项变化
  • 在线价格同步。 已移除后台与手动 LiteLLM 价格目录拉取、本地价格覆盖及未使用的价格管理界面。
  • 旧版 Codex 注入链路。 已移除随包 Opsail 辅助程序、Chromium 调试端口接入、渲染器注入和自动重启 Codex 的路径；挂件不再修改或控制 Codex 进程。
  • 自动更新说明文字。 高级设置中“自动检查更新”开关下方的说明文字已移除；开关与“立即检查”按钮的行为保持不变。
